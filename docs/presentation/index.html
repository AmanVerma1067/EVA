The Problem

Why Modern AI Coding & Operating Assistants Fail

1

The "Context Tax" & Token Bleed

Tools blindly dump entire codebases into prompts. This burns API quotas in minutes, dilutes model reasoning, and triggers weekly limits.

2

AI Over-Engineering & Lack of YAGNI

AI models default to inventing unnecessary classes, layers, and third-party dependencies instead of using standard library built-ins.

3

The "Dumb Parser" Fragility

Natural voice commands are parsed literally without inspecting environment state (e.g. "open antigravity over here" fails looking for app "over here").

4

Cloud Data Insecurity & Screen Leaks

Audio, screens, and terminal sessions stream to remote cloud servers, violating enterprise compliance and leaking API tokens.

Summary: Developers need an on-device, senior engineer agent that acts with discipline, token frugality, and native platform awareness.

Tech Stack & Rationale

High Performance, Type Safety & Zero Cloud Overhead

TypeScript 5.5 + Node.js 22 LTS (ESM)

Zero-compilation drift, modern ES2024 module syntax, strict typing (`noImplicitAny`), and event-driven non-blocking process supervision.

Why: Blazing speed, type safety, low memory (<50MB)
Zod 3.23 Contract Validation

Strict schema enforcement for inputs and outputs across all 28 tool contracts. Guarantees sanitized inputs before execution.

Why: Eliminates runtime payload bugs and injection
Native Objective-C & Clang Binaries

Direct bindings to macOS AVFoundation, Apple Speech, and Apple Vision (`VNRecognizeTextRequest`). Compiled into standalone binaries.

Why: Hardware acceleration on Apple Silicon, sub-150ms
Vitest 2.0 Parallel Testing Suite

High-speed testing framework executing all 38 test suites (206 unit and integration tests) in under 6 seconds with isolated mock contexts.

Why: Zero flakiness, immediate CI regression detection

Feature Deep-Dive 4

4-Tier Risk Policy & Tamper-Evident Hash Chain

4-Tier Deterministic Risk Policy
  • • READ: Inspection commands allowed automatically without user interruption.
  • • NORMAL: Low-risk mutations (opening apps, scheduling reminders).
  • • SENSITIVE: Modifying files, git commits, terminal commands, keystrokes.
  • • CRITICAL: Security permissions, credential access, external distribution.
security/policy/PolicyEngine.ts (12 Capability Gates)
Continuous SHA-256 Hash Chain
  • • Cryptographic Audit Chain: Every executed tool records a cryptographically linked hash (`prevHash` -> `hash`).
  • • Tamper Detection: Modifying any historical log invalidates the entire chain, proving unauthorized tampering.
  • • User-Only Storage: Stored under `~/.eva/audit/audit.jsonl` with strict `0o700` / `0o600` user permissions.
